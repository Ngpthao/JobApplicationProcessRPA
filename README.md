The goal is to automate the first administrative step of handling incoming job applications.

In a manual process, an HR employee usually has to:

- open the mailbox,
- search for application emails,
- download CVs and cover letters,
- create folders for candidates,
- rename files,
- update an applicant tracking Excel file,
- send a confirmation email,
- move the processed email to another folder.

The UiPath robot should perform these steps automatically.
